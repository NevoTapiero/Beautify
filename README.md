# Beautify

אפליקציית ניהול תורים וגלריית עבודות לקוסמטיקאיות — **אב-טיפוס ויזואלי (Prototype)**.

אפליקציה אחת, שני צדדים שמחוברים ביניהם:

- **צד מנהלת** (הקוסמטיקאית) — לוח בקרה, יומן תורים, ניהול לקוחות, גלריית עבודות עם אישור תמונות, הגדרות אוטומציה.
- **צד לקוחה** — הרשמה עם הצהרת בריאות, קביעת תור, אישור הגעה, תשלום בביט, גלריה ושיתוף תמונות.

> זהו אב-טיפוס להדגמה ולקבלת פידבק מלקוחות ראשונות — לפני פיתוח המערכת המלאה. הנתונים הם נתוני דמו בזיכרון בלבד (אין עדיין שרת / בסיס נתונים).

---

## הרצה מקומית

נדרש Node.js 18 ומעלה.

```bash
npm install
npm run dev
```

ואז לפתוח את הכתובת שמודפסת בטרמינל (בדרך כלל `http://localhost:5173`).

לבנייה לפרודקשן: `npm run build` (הפלט נשמר ב-`dist/`).

---

## איך מדגימים (זרימת ה-WOW)

החיבור בין שני הצדדים הוא הלב של ההדגמה:

1. עברו ל**תצוגת לקוחה** → קבעו תור (בחירת טיפול → יום → שעה → תשלום בביט).
2. עברו ל**תצוגת מנהלת** → התור החדש כבר מופיע ב**יומן** וב**לוח הבקרה**.
3. בתצוגת לקוחה → **גלריה** → שתפו תמונה.
4. בתצוגת מנהלת → **גלריה → לאישור** → אשרו, והתמונה נכנסת לגלריה.

## מה מכוסה ב-MVP

לפי המסמך שהוגדר, האב-טיפוס מכסה:

- קביעת וביטול תורים + ניהול לו"ז
- הרשמת לקוחות (שם, טלפון, מייל)
- טופס הסכמה / הצהרת בריאות בהרשמה (טיוטה — לאישור עו"ד)
- ניהול לקוחות והיסטוריה (חיפוש, חסימה, מחיקה, יצירת קשר, תזכורת ידנית)
- אישור הגעה (24 שעות לפני התור)
- תשלום בביט (סימולציה)
- גלריית עבודות + העלאת תמונות ע"י לקוחות באישור המנהלת
- הגדרות תזכורות אוטומטיות (תחילת יום / אחרי הפסקה / 24 שעות / שעה לפני)

## מה דמו ומה צריך פיתוח אמיתי (השלב הבא)

הדברים הבאים מודגמים ויזואלית אך **עדיין לא מחוברים למערכות אמיתיות**:

- **תשלום בביט** — דורש חשבון סליקה והטמעת ספק תשלומים.
- **תזכורות WhatsApp / SMS** — דורש WhatsApp Business API או ספק הודעות.
- **התחברות והרשמה אמיתית** — דורש שרת, מסד נתונים ואימות (Auth).
- **שמירת נתונים** — כרגע הכל בזיכרון; צריך בסיס נתונים.
- **חשבוניות אוטומטיות** — דורש חיבור לספק חשבונאי תקני (מס הכנסה).

## ארכיטקטורה (נוכחית)

- **React 18 + Vite**
- `lucide-react` לאייקונים
- כל המסכים נמצאים ב-`src/App.jsx` (קומפוננטה עצמאית אחת), העיצוב מוטמע בתוכה.
- ללא תלות בספריות עיצוב חיצוניות.

```
beautify/
├─ index.html
├─ package.json
├─ vite.config.js
└─ src/
   ├─ main.jsx      # נקודת כניסה
   ├─ App.jsx       # כל האפליקציה (מנהלת + לקוחה)
   └─ index.css     # reset בסיסי
```
